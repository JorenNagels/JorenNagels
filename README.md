## Now

At Immoweb I led the rewrite of Realo from PHP to Next.js — page by page, alongside the
live site, so nothing went dark during the migration. Authentication moved onto the new
stack first, including 2FA and passkeys, while the PHP site kept serving traffic.

I set that codebase up agent-first: built with Claude Code from the start, with docs and
skills so AI agents can work in it productively. I was one of the first at the company to
use it daily, brought it into the team, wrote shared skills and helped colleagues get going.

## Before

Four years at Realo as a software engineer:

- **Vlabel** — the property valuation tool for the Flemish Tax Administration: transaction
  search, comparison points and the official valuation report.
- **Sales back office** — quotes, subscriptions and invoicing for estate agencies.
- **Valuation reports** for estate agencies, including white-label versions.
- **Saved searches** — matching new listings land in an agency's CRM as leads.
- **Infrastructure** — moved the whole stack to Docker on AWS ECS, which lowered AWS costs
  and sped up deploys, then upgraded PHP 7.4 → 8.4.
- Onboarded and mentored the engineers who joined after me, and introduced pull requests
  and code review in place of committing straight to `main`.

Earlier I co-founded **Rocket Core**, running esports tournaments — I handled players and
sponsors, and built the site.
